# project52
52 Weeks, 52 Rust Projects

## Goals
Write a small project roughly every week using the Rust Programming Language. 

## Why
Always looking to improve my software skills and knowledge. Also, I saw several videos, blogs, and posts with positive reflections after undergoing project52. I would love to focus more on the Rust language, Databases, Embedded Systems, Protocols, and other common software paradigms 

## Constraints
- The project can be small or big but not re-writing an old project. New material should be developed.
- Rust Programming Language should be utilized. Additional languages can be added but not limited.
- 52 projects deadline is the year end not 1 per week.
- Should be useful or functional that I would use it after its finished.
